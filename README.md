# שיינדי וינברגר — דף נחיתה: שיחת פיצוח

דף נחיתה לעסק "שיחת פיצוח" של שיינדי וינברגר, בפורמט חד־עמוד המותאם לנייד ולמחשב.

## כתובת האתר

הדף מתפרסם תחת: **https://sikatmisrad.com**

## מבנה התיקייה

```
build/
├── index.html   ← העמוד הראשי (הבחירה הסופית)
├── images/      ← כל התמונות בהן משתמש העמוד (לוגו, גיבורים, המלצות, עבודות)
├── pdf-gen.js   ← סקריפט עזר (Node/Puppeteer) להפקת PDF של העמוד
├── CNAME        ← מחזיק את הדומיין sikatmisrad.com
└── .nojekyll    ← מבטיח שקבצי העמוד מועלים ללא עיבוד
```

## הערות למסירה

- **כל תמונות העמוד** ממוקמות בתיקיית `images/` בתוך התיקייה, כך שאין תלות בקישורים חיצוניים מלבד גופני Google Fonts.
- דף התשלום (קישור לגבייה) מקושר לשירות סומי"ת.
- העמוד נכתב בעברית עם כיווניות RTL מלאה, מותאם לכל רוחב מסך (רספונסיבי).

## טכנולוגיה

- HTML / CSS / JavaScript טהור בתוך קובץ אחד — ללא בנייה (build) וללא תלות בספריות.
- גופנים נטענים מ־Google Fonts (Assistant).
